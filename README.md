IT Inventory Management — Python Project

I built a simple Python program to track a company’s laptop inventory. Users can add approved laptop models, remove devices, view the inventory, and exit the program.
What I used:
- A tuple to store approved laptop models.
- A list to store the current inventory.
- A while loop to keep the menu running.
- If/elif/else statements to handle user choices.
- Validation checks to reject unapproved models and prevent errors when removing devices.

What I learned:
This project helped me understand how tuples, lists, and loops work together. I also learned how to check user input and safely add or remove items from a list.

Technology: Python
Interface: Terminal
